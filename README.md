# A Unity Project for NTUT Master Thesis - Unity Simulation for Real-Time Person Re-Identification and Tracking

This Unity project runs a simulation environment populated with walking people and streams the video feeds of the virtual cameras by TCP. 

Scenes used in the Experiments can be found in Assets/Scenes:
+ Eval0 (Scenario 0 Day and Scenario 0 Day-Night)
+ Eval1 (Scenario 1)
+ Eval2 (Scenario 2)
+ WalkingTest (for testing purposes)

Make sure to correct set the correct IP and Port for the virtual cameras.
